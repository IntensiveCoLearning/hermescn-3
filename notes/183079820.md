今天是开营的第一天，以前其实也很少用 Hermes、Openclaw 这样的 AI Agent ，我个人觉得，如果再继续使用类似 Openclaw 这样的 AI Agent，我的 AI 用量会成倍增加，产生的费用我有点承担不住。

我之前是在网页上使用订阅制的 ChatGPT Plus，还有一些是用官方或中转站的 API 来使用 AI。后来，我在 Linux Do 上搞了很多公益站的模型，把这些公益站的 API 加入到 Openclaw 时，发现预期并不是很好。这有可能是跟模型有关，也有可能是工具本身正在迭代，总而言之，当时让我觉得它并没有那么好用。

现在重新回过头来学习，其实也是一种再一次加深了解和尝试吧，毕竟也迭代了这么多版本，应该会有不一样的效果。目前我用 Codex 和 Cloud Code，还用了一个社区版的套壳版 Cloud Code，叫 New Max。发现 New Max 用起来还是非常不错的，它也是另外一种 AI Agent。反正说了这么多，其实主要还是今天来重新体验一下：

1. 搭建了 Hermes 的网关，并在本地对其做了一些升级，现在相当于更新到了最新版本。（发现一个问题：Hermes 没有适配英特尔芯片 MacBook Pro 的桌面客户端，只能通过终端或网关使用。终端操作不够直观，不如网关顺手，所以我最终选择了搭建 Web 网关，如图。）
2. 使用了我之前订阅的 Open Code Go 套餐中的 DeepSeek 多模态模型。感觉效果还不错，目前用起来整体打个七八十分的样子吧，因为还没有进行一些更深度的交互，所以评分也或许并不客观。

第一天的任务圆满完成！今天第一天大概就是这样。把整个环境其实也是用 AI 来搭的过程，比如说搭建的时候会出现一些 TUI 的问题，在升级的过程中也会提示某些包有问题，这些过程中我都是用 DeepSeek 来解决的。
