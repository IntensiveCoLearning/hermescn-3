## **跨机：peer vs Desktop**

**peer 是 bot 自己的电话线；Desktop 是你的操控台。** 要办事 → peer。要讨论、要看见 → Desktop。

![1.00](https://cdn.intensivecolearn.ing/images/programs/cmtfruwwx1ev1ro29dtsjp8v6/checkins/f20ER99u8IIZlkSDlo9HkyukgySZLs8g/2026-09/62999390-5545-4759-8b80-f7e45273cb9a.png)

### **用 peer 的场景**

* **定时任务**：凌晨 3 点 cron 让 24G 的 bot 去问 `mini16/hermes-glm` 训练结果，再发 Discord。你在睡觉，Desktop 关着

* **消息触发**：Discord 来消息 → 24G bot 判断要问对面 → `message_agent(target="mini16")` → 回 Discord。**全程不经 GUI**

* **命令行**：

  ```
  hermes peer dm mini16 < q.txt                      # 短问题
  ```

  `hermes peer run mini16 --idempotency-key job-42 < t.txt   # 长任务，返回 run_id`

  `hermes peer status mini16 run_abc123`

### **用 Desktop 的场景**

* **跨机群聊**（peer 做不到）

* 浏览对面 bot 的历史会话

* 在对面机器上建 bot（New Agent 的 **Create on** 选择器）

* **Update all instances** 一次更新所有机器 ⚠️ 误点会更新 16G

### **混合用**

Desktop 群聊里发起讨论 → 某个 bot 需要 16G 数据 → 它自己走 peer 去拿。 **同一次协作里两条路都用上**，不是二选一。
