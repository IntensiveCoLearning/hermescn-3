# 六、第一次真正理解“额度”和“模型能力”是两个问题

```

```

这些问题让自己第一次比较清楚地理解：

```
模型本身
≠
Provider
≠
账户额度
≠
网络连接
```

例如：

### 额度问题

```
HTTP 429
Weekly / Monthly Usage Limit
```

这种情况并不是本地 Hermes 安装有问题，而是账户资源达到上限。

### 上游拥堵

```
temporarily at capacity upstream
```

则表示模型服务当前负载较高。

### 网络问题

例如 GitHub：

```
Failed to connect to github.com:443
```

则属于网络连接问题。

现在开始习惯先判断：

```
到底是哪一层出了问题？
```

再决定修什么，而不是看到一个错误就直接重新安装。
