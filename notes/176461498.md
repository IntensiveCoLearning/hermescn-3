## 五、第一次遇到的问题

在首次使用过程中，也实际遇到了一些模型 Provider 和额度相关的问题。

例如：

```
HTTP 429
```

以及模型额度不足、Provider 不可用等情况。

通过这些问题开始认识到：

```
Hermes
≠
单一模型
```

Hermes 可以连接不同的 Provider 和模型，因此当某个模型出现额度限制或服务异常时，可以通过切换模型继续工作。

这也为后续学习多模型协作和故障恢复打下了基础。
